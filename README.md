# Superstore Sales & Profitability Analysis

Aggregated regional sales and product profit margins across 9,000+ retail orders using SQL and Google Sheets to evaluate overall business profitability.

## Tools Used
- SQL (SQLite)
- Google Sheets

## Key Findings
- Top Sales Region: West Region generated the highest revenue ($725,457.82), followed by East ($678,781.24).
- Most Profitable Category: Technology was the highest profit driver ($145,454.95), whereas Furniture was lowest ($18,451.27).
- Unprofitable Orders Identified: Isolated 1,871 loss-making orders across product categories.

## Files
- `SampleSuperstore.csv` - Raw retail dataset
- `queries.sql` - SQL aggregation scripts
- `superstore_chart.png` - Regional sales visualization chart
